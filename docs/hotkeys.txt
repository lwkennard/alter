
 DESKTOP
   Super+1..4 / +Shift    go to workspace N / move window there
   Super+Alt+Left/Right   previous / next workspace
   Super+Shift+Left/Right move window to previous / next workspace
   Super+Space            switch window (rofi); Super+W with 2+ layouts
   Ctrl+N / Ctrl+P        rofi: next / previous match
   Super+V                clipboard history
   Ctrl+Alt+T             new terminal
 WINDOWS (PAPERWM)
   Super+arrows           focus window left / right / up / down
   Super+, / Super+.      previous / next window
   Super+Ctrl+arrows      move window left / right / up / down
   Super+Tab / Alt+Tab    cycle windows
   Super+Shift+Alt+arrows focus other monitor
   Super+Shift+Ctrl+arrow move window to other monitor
   Super+I / Super+O      pull next window into column / push it out
   Super+R / +Shift       cycle window width / height
   Super+F / +Shift       maximise width / fullscreen
   Super+C                centre window
   Super+Return           new window
   Super+BackSpace        close window
   Super+`                back to previous workspace
   Super+Escape / +Shift  toggle scratch window / scratch layer
 TERMINAL (GHOSTTY)
   Ctrl+Shift+T / W       new / close tab
   Ctrl+PgUp/PgDn, Alt+N  previous / next tab, tab N (Alt+9 = last)
   Ctrl+Shift+PgUp/PgDn   move tab left / right
   Ctrl+Shift+O / E       split right / down
   Ctrl+Shift+arrows      focus split left / right / up / down
   Ctrl+Shift+Enter       zoom / unzoom split
   Ctrl+Shift+N / Q       new window / quit
   Ctrl+Shift+C / V       copy / paste
   Shift+Up/Down          scroll up / down one line
   Ctrl+Plus / - / 0      font bigger / smaller / reset
   Ctrl+Shift+P / +,      command palette / reload config
 SHELL
   Ctrl+R                 search command history (fzf)
   Ctrl+T / Alt+C         insert a file path / cd into a directory (fzf)
   z DIR / zi / z -       jump to visited dir / pick / back (zoxide)
   ll / la / lt           list long with git / all / tree (eza)
   bat FILE               view a file with highlighting
   fd PATTERN             find files by name
   rg PATTERN             search file contents
   git diff / show / log  diff rendered by delta
   gh                     GitHub CLI: gh pr, gh issue, gh auth
   fetch / reset          reprint banner / reset + banner (fastfetch)
   starship explain       what each prompt segment means
   keys [PATTERN]         this list, filtered
